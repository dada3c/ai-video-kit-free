# brand.md：董達達3C私塾

## 配色（覆蓋 design-system.md 的 token）

> 取自部落格主色草綠 `#729c0b`，調亮後放在深色底上。（配色為建議方案，使用者尚未最後確認）

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#16242B` | 深墨藍綠底色 |
| `--ink` | `#F4F1E8` | 主要文字 |
| `--r1` | `#F2A65A` | 暖橘：警示、限制、要注意的地方 |
| `--r2` | `#E9C46A` | 芥末黃：次要強調、數字 |
| `--r3` | `#A6CE39` | 亮草綠：**本集主角**（部落格同色系） |
| `--r4` | `#6F8A96` | 灰藍：中性、對照組 |
| `--muted` | `#A3B4BB` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 圖解以**手機／電腦畫面示意、步驟流程、對照表**為主。
- 步驟類內容用編號（1 → 2 → 3）一步一個畫面。
- 規格、價格、日期用大數字呈現，旁邊標出處。
- 「台灣能不能用」這類限制，用警示色 `--r1` 標出來。
- 不使用未經授權的品牌 logo 與官方產品圖；用文字或簡化示意圖代替。
- 不出現家人的臉部照片或姓名。
