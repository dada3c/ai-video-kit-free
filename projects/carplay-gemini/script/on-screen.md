# 畫面文字建議（給分鏡參考，不是分鏡表）

| 口播 | 畫面建議 |
|---|---|
| CarPlay 怎麼用 Gemini？ | 開頭大字：「CarPlay 怎麼用 Gemini？」；車機螢幕示意，圖示亮起 |
| 四個步驟，第三步最常被漏掉。 | 「4 步驟」大數字；1～4 四個圓點，第 3 個用警示色標出 |
| Google 十一月十一號宣布：Gemini 上 CarPlay 了。 | 日期卡「11/11」＋「Google 官方公告」出處小字 |
| 開車時用講的，就能問行程、聽未讀信。 | 兩個對話泡泡：「今天行程？」「唸未讀信」；麥克風聲波 |
| 第一步，Gemini 更新到最新版。 | 步驟卡 1：手機 App 更新示意 |
| 第二步，打開麥克風權限。 | 步驟卡 2：開關從關到開，麥克風圖示 |
| 第三步，先在手機用一次 Gemini Live。 | 步驟卡 3（警示色強調）：手機上的語音對話示意 |
| 官方列為必要步驟，不是建議。 | 膠囊標籤「必要步驟」，「建議」兩字被劃掉 |
| 第四步，接上車，點螢幕上的 Gemini。 | 步驟卡 4：手機連到車機，點圖示 |
| 台灣可以用，中文也能講。 | 「台灣 可以用」「中文 可以講」兩個打勾 |
| 功能分批開放，沒看到就過幾天再看。 | 日曆翻頁示意；小字「分批開放」 |
| 我是董達達。 | 名字卡「董達達」 |
| CTA 兩句 | CTA 版型：問句＋「追蹤」放大＋ @dada3c.tw |

注意：不使用 Google、Apple 的官方 logo 與產品圖，用文字與簡化示意圖。
